# 任务清单：乡音地图 HarmonyOS App

## 任务 1：创建最小 HarmonyOS 工程骨架

**描述：** 建立 Stage 模型 `entry` 模块、应用配置、资源目录、Ability 和最小首页，使工程首先达到可识别、可编译状态。

**验收条件：**

- [x] 工程包含根级与 `entry` 级 Hvigor 配置。
- [x] `EntryAbility` 能加载首页路由。
- [x] 应用名称、包名和图标资源使用乡音地图标识。

**验证：**

- [x] 执行 `hvigorw assembleHap --no-daemon --stacktrace`。
- [x] 已产出 `entry/build/default/outputs/default/entry-default-unsigned.hap`；当前未配置签名。

**依赖：** 无
**预计文件：** 根配置、`AppScope` 配置、`entry` 配置、Ability、最小页面
**规模：** M（4-5 个逻辑文件组）

## 任务 2：定义展示模型和模拟服务

**描述：** 定义地图点位、同乡用户、鉴定结果和乡音护照模型，提供确定性的本地模拟数据和范围校验。

**验收条件：**

- [x] 所有百分比分数限制在 `0..100`。
- [x] 同乡列表包含附近、推荐和当前区域三种来源。
- [x] 模拟服务不请求网络、位置或麦克风权限。

**验证：**

- [x] 单元测试已编译进 `entry-ohosTest-unsigned.hap`；当前无连接设备，尚未执行。
- [x] 主 HAP 与 `ohosTest` HAP 均通过 Hvigor 构建。

**依赖：** 任务 1
**预计文件：** `models/DialectModels.ets`、`services/MockDialectService.ets`、对应测试
**规模：** M（3 个文件）

## 任务 3：首页地图与同乡面板

**描述：** 实现地图主视觉、乡音点位、缩放/平移/定位和可折叠底部面板，展示三类同乡。

**验收条件：**

- [x] 地图支持缩放、平移和恢复定位。
- [x] 点位显示方言与同乡数量。
- [x] 面板支持折叠/展开并切换附近、推荐、当前区域。

**验证：**

- [x] 执行 Hvigor 构建。
- [ ] 在 Previewer 或设备上人工检查地图与面板状态；若不可用则明确报告。

**依赖：** 任务 2
**预计文件：** 首页、地图组件、面板组件、地图资源
**规模：** M（4 个文件）

## 任务 4：同乡用户到乡音护照

**描述：** 从任一同乡用户卡片进入乡音护照，展示身份、方言指标、代表语音、点亮地区和社交统计。

**验收条件：**

- [x] 点击同乡卡片进入对应护照。
- [x] 护照完整展示规格中的九类信息。
- [x] 代表语音和分享入口提供可见的演示状态。

**验证：**

- [x] 执行 Hvigor 构建。
- [x] 护照由同一 `FellowUser` 模型生成，静态检查数据源一致；运行态待设备验证。

**依赖：** 任务 3
**预计文件：** 护照页、护照组件、路由参数处理
**规模：** M（3 个文件）

## 任务 5：模拟录音鉴定与地区点亮

**描述：** 从首页进入录音状态机，完成模拟鉴定、地区确认、点亮地区，并生成当前用户乡音护照。

**验收条件：**

- [x] 录音具有准备、录音中、完成和鉴定结果状态。
- [x] 结果包含方言归属、置信度和乡音保留度。
- [x] 页面明确显示“模拟鉴定”。
- [x] 点亮地区后可进入当前用户护照。

**验证：**

- [x] 鉴定服务和护照生成测试已编译进 `ohosTest` HAP，待设备执行。
- [x] 主 HAP 与测试 HAP 均通过 Hvigor 构建。
- [ ] 完整核心流程待 Previewer 或设备人工走通。

**依赖：** 任务 2、任务 4
**预计文件：** 鉴定页、状态组件、服务测试、首页状态连接
**规模：** M（4 个文件）
