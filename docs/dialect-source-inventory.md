## 结论先行

这批资料可以为乡音地图补上“方言分类依据、方言区详情、语音/语法解释和内容选题”四类能力，但不能直接把扫描地图裁切进应用，也不能把《方言》期刊目录当成已经获得的论文数据。

首版最值得接入的是：

1. 用《中国语言地图集（第2版）·汉语方言卷》复核“大类—片区—地方口音”的分类层级。
2. 用《汉语方言地图集·语音卷》补充鉴定结果的“识别依据”和方言区详情中的语音特征。
3. 用《汉语方言地图集·语法卷》补充方言详情页的语法例句或语法特征卡。
4. 用《汉语方言解释地图》借鉴面向普通用户的解释方式和地图叙事，不把它当作唯一分类权威。
5. 用《方言》2016—2026整理包建立研究选题索引，后续在获得授权和登录后逐篇核验全文。

## 可以落到乡音地图的 5 个产品模块

### 1. 方言分类层

当前应用已经使用：

```text
方言大类 → 方言片区 → 地方口音 → 代表地区
```

这批资料可以帮助把当前演示分类从“产品假设”升级为“待来源核验的分类版本”。建议新增数据字段：

```text
classificationId
dialectFamily       方言大类
dialectGroup        方言片区或次级分区
dialectBranch       地方口音/小片
representativePlace 代表地区
sourceTitle         来源资料
sourceEdition       资料版本
sourcePage          页码或图表编号
boundaryStatus      核心区/过渡区/待核验
rightsStatus        可展示/仅内部研究/待授权
```

注意：方言区不是省份区划。比如广东不能整体等同于粤语区；地图上应显示方言片区和代表地点，而不是给省份贴单一方言标签。

### 2. 方言地区详情页

参考《汉语方言解释地图》的解释型方式，可以为地图点位增加次级页面：

- 方言名称与层级归属。
- 大致分布范围和代表城市。
- “核心区/过渡区/范围待核验”状态。
- 语音特征卡：声母、韵母、声调或音系现象。
- 语法特征卡：句式、助词或语序现象。
- 代表词汇与例句。
- 该地区的乡音用户和代表语音。

这个页面应与“乡音护照”分开：地区详情介绍方言，乡音护照介绍个人。

### 3. 可解释鉴定结果

《语音卷》最适合支持当前鉴定页的“识别依据”模块。当前固定文案可以逐步替换为有出处的特征记录：

```text
候选结果：重庆话 · 成渝片
识别依据：声母/韵母/声调特征与该片区资料相近
参考来源：语音卷，第 X 图/第 X 页
结果状态：演示推断 / 用户确认 / 待专业复核
```

在真实模型接入前，不能把资料中的统计特征包装成“AI 已识别”；仍需显示模拟或待复核状态。

### 4. 乡音词汇与语音任务

可以从资料中筛选短、易读、具有地区辨识度的内容，形成录音前的任务卡：

- “说一句家乡问候”。
- “说出当地对某种食物的叫法”。
- “读一组同义词，比较不同地区的发音”。

每个任务需要保留：词条、拼音/音标、地区、来源、版权状态、适合的录音时长。没有完成人工核对前，不应直接把期刊论文中的例句投放给普通用户。

### 5. 内容与研究入口

《方言》整理包适合做内部内容工作台，而不是直接塞进用户首页：

- 按年份和期号建立研究索引。
- 按地区、方言片区、主题筛选文章题目。
- 将“语音、词汇、语法、接触、保护、调查”等主题映射到方言详情页。
- 文章只显示已确认的题名、作者、期次和官方入口。
- 全文下载必须由有权限的用户在官方平台完成。

## 推荐的首批落地范围

不要一次性把 4 本大部头资料全部数字化。建议先做 4 个可验证样本：

| 样本 | 产品用途 | 需要从资料核对的内容 |
| --- | --- | --- |
| 重庆话/成渝片 | 当前主流程与点亮示例 | 分类层级、代表地区、1–2 个语音特征 |
| 上海话/苏沪嘉小片 | 吴语对照样本 | 分类层级、词汇或语法示例 |
| 广州话/广府片 | 粤语对照样本 | 代表地区不能扩展成整个广东 |
| 北京话/北京官话 | 官话内部对照样本 | 与西南官话的层级差异和语音特征 |

首批样本通过人工核验后，再扩展到更多片区。每个样本至少需要一条来源页码、一个资料版本和一个版权状态。

## 不建议现在做的事

- 不从 PDF 截图直接裁切地图作为应用资源。
- 不把方言边界画成行政边界或绝对实线。
- 不把《东言西语》的科普观点当作分类标准。
- 不把期刊目录中出现的论文题目当作已读取的全文内容。
- 不在没有麦克风、模型和隐私授权的情况下宣称真实方言鉴定。
- 不把资料中的方言例句批量导入用户录音任务，直到完成来源、版权和语言学核验。

## 当前结论

这批资料最现实的使用方式是：

```text
地图集提供分类与地理基线
语音卷提供鉴定解释素材
语法卷提供地区详情内容
解释地图提供普通用户叙事方式
《方言》目录提供后续研究索引
科普书提供文案语气与故事灵感
```

它们能显著提升乡音地图的可信度和内容深度，但目前还不能直接替代经过授权的 GIS 方言边界数据、录音语料库或真实鉴定模型。
