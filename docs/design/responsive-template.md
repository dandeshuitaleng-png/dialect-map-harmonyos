# 响应式页面模板

布局由实际窗口宽度驱动，不按设备型号硬编码。

## 窗口矩阵

| 窗口宽度 | 栅格基线 | 首页架构 | 录音任务 | 护照 |
| --- | --- | --- | --- | --- |
| `<600vp` | 4 栏，边距 16vp | 地图 + 底部面板 | 底部半模态，可扩展 | 单列滚动 |
| `600–839vp` | 8 栏，边距 24–32vp | 竖屏仍为地图 + 底部面板；横屏可并列 | 半模态或窄侧栏 | 身份区 + 内容重排 |
| `≥840vp` | 12 栏，边距 32vp | 横屏地图主区 + 至少 360vp 侧栏 | 侧栏任务区 | 身份主卡 + 详情列 |

## 首页模板

### 竖屏

```text
┌──────────────────────────┐
│                          │
│        地图主视觉         │
│      点位 / 定位按钮       │
│                          │
├────── 乡音面板把手 ───────┤
│  区域与代表点摘要          │  紧凑约 220vp
│  录音鉴定 / 我的护照       │
│  人物样例列表              │
└──────────────────────────┘
```

- 竖屏平板提供紧凑约 220vp、半展开约 42%、充分展开约 72% 三个吸附层级。
- 上拖展开、下拖收起；过程连续跟手，松手按速度和距离吸附。
- 列表滚动到顶部继续下拉时才允许面板收起，避免手势抢夺。

### 横屏大窗口

```text
┌──────────────────────────────┬──────────────┐
│                              │ 区域与入口    │
│          地图主区             │ 乡音分类      │
│                              │ 人物样例      │
│                              │              │
└──────────────────────────────┴──────────────┘
```

- 地图优先获得剩余空间；侧栏最小 360vp。
- 侧栏独立滚动，不覆盖地图。
- 选择点位只更新侧栏内容，不切换页面。

## 录音任务模板

- 窄窗口：从底部进入，显示关闭、任务阶段和单一主操作。
- 宽窗口：替换乡音侧栏内容或在同一侧栏进入子层级，地图保持可见。
- 任何窗口关闭后都恢复进入前的地图和面板状态。
- 键盘弹出时主按钮和当前输入不得被遮挡。

## 护照模板

### 窄窗口

1. 标题栏与分享入口。
2. 身份主卡。
3. 两项鉴定指标及解释。
4. 乡音短句文字样例。
5. 已点亮地区。
6. 本机体验说明。
7. 分享个人乡音名片。

### 宽窗口

- 左列：身份主卡、乡音短句、分享。
- 右列：鉴定指标、点亮地区、本机体验说明。
- 不把手机单列等比放大；增加并行信息，不增加无意义留白。

## 连续性

横竖屏、折叠开合、分屏和自由窗口切换时必须保留：

- 当前页面和任务阶段。
- 地图中心、缩放、倾斜与旋转状态。
- 已选择点位与地区筛选。
- 面板收展状态或对应侧栏选区。
- 本机模拟鉴定结果和生成的护照。
- 键盘焦点与滚动位置；无法保持时回到最接近的语义位置。
