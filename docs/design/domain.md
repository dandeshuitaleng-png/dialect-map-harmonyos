# 乡音领域语义

## 核心对象

| 对象 | 含义 | 不应被误解为 |
| --- | --- | --- |
| 乡音点位 | 某地区存在可展示的方言内容或用户样例 | 用户精确实时位置 |
| 同乡 | 按方言归属、籍贯或用户自我认同形成的关联 | 法律意义上的户籍认定 |
| 方言归属 | 本次语音样例与某方言类别的匹配结果 | 用户永久且唯一的身份 |
| 鉴定置信度 | 系统对本次方言分类结果的确定程度 | 口音纯正程度 |
| 乡音保留度 | 语音中仍保留目标方言特征的相对程度 | 方言能力、文化价值或个人优劣 |
| 点亮地区 | 用户完成鉴定或主动记录过的地区 | 当前所在位置或真实足迹证明 |
| 乡音护照 | 汇总用户乡音身份与互动数据的产品名片 | 官方证件或权威认证 |

## 数据表达规则

- [项目事实] 当前鉴定、同乡关系和用户数据为本地模拟数据。
- 所有模拟结果必须在结果附近说明，不能只在首次引导中说明一次。
- 百分比分数限制在 0–100，并说明指标含义。
- 不使用“纯正”“标准”“不标准”等带价值评判的词评价个人口音。
- 不根据一次短录音推断民族、职业、教育、经济状况或精确籍贯。
- 地图同乡点位默认使用聚合或地区级位置，不展示精确住址。

## 可信与隐私

- 原始录音、精确位置属于敏感数据，不进入普通日志。
- 分享名片默认不包含原始录音文件、精确位置和隐藏关系数据。
- 定位权限在用户点击“我的位置”时申请；拒绝不能阻断地图浏览。
- 未来接入真实录音时，在用户点击录音动作后再申请麦克风权限。
- 真实 AI 结果必须说明模型/服务来源、时间、失败和人工纠正路径。

## 指标文案

### 鉴定置信度

推荐说明：

> 表示系统对本次方言分类结果的确定程度，不代表口音优劣。

### 乡音保留度

推荐说明：

> 表示这段语音中保留目标方言特征的相对程度，仅供乡音记录参考。

### 演示结果

推荐说明：

> 当前为本地模拟鉴定，用于展示产品流程，不代表真实 AI 识别结果。

## 领域验收

- 用户能说出两个百分比指标的区别。
- 用户不会把乡音护照误认为官方身份认证。
- 用户能看出哪些数据是模拟，哪些来自真实系统能力。
- 用户拒绝位置权限后仍能完成地图浏览和录音演示。
- 分享前能预览将要公开的内容。
