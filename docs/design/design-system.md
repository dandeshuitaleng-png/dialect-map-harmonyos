# 视觉系统执行规则

## 品牌基线

- 页面与本地地图以宣纸暖白为底，不使用纯白大面积铺底。
- 黛青是品牌主色和关键操作填充色；低饱和土色只用于头像、乡土记忆和少量辅助识别。
- 文字色与填充色分离：例如 `accent_text` 用于浅底文字，`accent` 用于强调填充，不能因“颜色接近”互换。
- 内容层级优先使用背景差、1vp 细边框和微阴影；阴影不承担唯一分组信息，也不叠加成厚重悬浮卡片。
- 仅底部半模态使用 `surface_glass`、背景虚化与单层高光边缘建立空间关系，使拖动时能透出少量地图色彩；地图画布不叠加品牌标题卡，普通列表行也不使用磨砂，避免玻璃效果泛滥。
- 品牌渐变仅用于标题引导线和第一主操作，并由 `accent_gradient_start/end` 管理；两端都必须通过白字对比度检查。

## 角色优先于色值

实现时优先使用资源和语义角色，不在组件中临时扩散裸色值。

| 角色 | 用途 | 禁止用途 |
| --- | --- | --- |
| `background_page` | 宣纸暖白页面基础背景 | 选中或警告 |
| `surface_primary` | 面板与稳定内容主体 | 每一行都做独立重卡 |
| `surface_elevated` | 少量抬升内容面 | 页面整屏铺底 |
| `surface_sunken` | 分段控件底槽、低层分组 | 主操作 |
| `ink_primary` | 标题、关键数据 | 大面积弱说明 |
| `ink_muted` | 正文、辅助字段 | 主 CTA |
| `ink_tertiary` | 时间、弱说明 | 唯一错误信息 |
| `accent` | 黛青主操作、关键选中填充 | 浅底小字 |
| `accent_text` | 浅底黛青强调文字 | 大面积按钮填充 |
| `brand_soft` | 低强度选中与品牌柔和底 | 主按钮文字 |
| `confirm` / `confirm_text` | 点亮、保存和对应浅底文字 | 方言类别装饰 |
| `danger` | 权限、网络、校验失败 | 未选择状态 |
| `border` / `divider` | 内容面边界与行分隔 | 唯一焦点反馈 |
| `focus` | 键盘与遥控焦点 | 装饰描边 |
| `shadow_card` / `shadow_soft` | 内容面微抬升、顶层面板 | 多层重阴影 |

## Token 规则

- [官方规范] 尺寸使用 `vp`，字体使用 `fp`。
- Light 与 Dark 分别定义语义资源，不直接反转或复用浅色裸值。
- 文本 Token 与填充 Token 分开选择；错误、确认和品牌强调都必须保证浅底文字对比度。
- hover、pressed、selected、disabled 从基础角色派生，不为单个页面另造近义颜色。
- 找不到合适 Token 时先登记 `gaps.log`；不得静默写入新的随机色、间距或时长。
- 当前工程中的常量应逐步迁移到资源或集中 Token；本轮文档不修改既有代码。

## 字体层级

| 语义 | 建议基线 | 用途 |
| --- | --- | --- |
| 展示 | 28fp Bold | 护照身份或结果主信息，大窗口不机械放大 |
| 标题 | 20fp Bold | 页面标题、主要分组 |
| 子标题 | 16fp Medium/Bold | 用户名、方言名称、卡片标题 |
| 正文 | 14fp Regular | 主要说明与字段 |
| 说明 | 12fp Regular/Medium | 来源、模拟声明、时间 |

大字体下允许换行和容器增高；操作文字不得被固定高度裁切。

## 图标与地图资产

- 优先使用 HarmonyOS Symbol；自定义图标保持统一线宽、圆头和视觉重量。
- 定位、播放、分享、返回等图标不能一套填充一套描边混用。
- 地图点位至少具备默认、选中、聚合、当前位置和已点亮五种语义。
- 本地地图兜底资源必须保持比例，不拉伸中国轮廓。
- 本地底图和点位必须使用同一经纬度投影与同一裁剪坐标平面；不得再为单个点位手调独立比例坐标。
- 页面先显示本地地图；在线地图只有在底图与 Marker 都成功后才覆盖本地层。
- 应用图标发布前需完成前景/背景双层资源；当前 SVG 仅为工程占位。

## 群聊模式

- 群聊默认进入“会话”（已加入群组），推荐/按方言只作为发现入口；所有入口使用连续列表行，不使用推荐重点卡或介绍 Hero。
- 聊天页以消息流为主体，示例消息和本人本机消息必须在发送者与状态文字上可区分。
- 未加入时输入区禁用；加入后才可发言，退出后立即恢复禁用。
- 输入区使用 `KeyboardAvoidMode.RESIZE_WITH_CARET`，让消息列表收缩而不是把标题栏整体顶出窗口。
- 本机消息单条最多 120 字、每群最多 100 条；达到上限后禁用继续发送。

## 动效 Token

| Token | 基线 | 用途 |
| --- | --- | --- |
| `motion_instant` | 100ms | 颜色、图标反馈 |
| `motion_short` | 150ms | 按压、选中 |
| `motion_panel` | 250ms 以内 | 面板非跟手落位 |
| `motion_page` | 350ms 以内 | 页面层级切换 |

跟手地图、面板拖拽不使用固定延迟；仅对结束后的落位使用曲线。
