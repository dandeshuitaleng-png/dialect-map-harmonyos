# 视觉系统执行规则

## 角色优先于色值

实现时优先使用资源和语义角色，不在组件中临时扩散裸色值。

| 角色 | 用途 | 禁止用途 |
| --- | --- | --- |
| `background_primary` | 页面基础背景 | 选中或警告 |
| `surface_primary` | 面板、护照主体 | 每一行列表 |
| `surface_secondary` | 次级分组、空状态 | 主操作 |
| `text_primary` | 标题、关键数据 | 大面积弱说明 |
| `text_secondary` | 正文、辅助字段 | 主 CTA |
| `text_tertiary` | 时间、来源、弱说明 | 唯一错误信息 |
| `brand_primary` | 录音主操作、关键选中 | 普通装饰 |
| `brand_surface` | 选中地区、低强度强调 | 主按钮文字 |
| `map_marker` | 普通乡音点位 | 错误状态 |
| `map_marker_selected` | 当前选中点位 | 所有点位 |
| `success` | 点亮、保存、分享准备完成 | 方言类别 |
| `warning` | 模拟声明、需要注意的限制 | 普通说明 |
| `error` | 权限/网络/鉴定失败 | 未选择状态 |
| `focus_ring` | 键盘与遥控焦点 | 装饰描边 |

## Token 规则

- [官方规范] 尺寸使用 `vp`，字体使用 `fp`。
- Light 与 Dark 分别定义语义资源，不直接反转或复用浅色裸值。
- hover、pressed、selected、disabled 从基础角色派生，不为单个页面另造近义颜色。
- 找不到合适 Token 时先登记 `gaps.log`；不得静默写入新的随机色、间距或时长。
- 当前工程中的常量应逐步迁移到资源或集中 Token；本轮文档不修改既有代码。

## 字体层级

| 语义 | 建议基线 | 用途 |
| --- | --- | --- |
| 展示 | 28fp Bold | 护照身份或结果主信息，大窗口不机械放大 |
| 标题 | 20fp Bold | 页面标题、主要分组 |
| 子标题 | 16fp Medium/Bold | 用户名、方言名称、卡片标题 |
| 正文 | 14fp Regular | 主要说明与字段 |
| 说明 | 12fp Regular/Medium | 来源、模拟声明、时间 |

大字体下允许换行和容器增高；操作文字不得被固定高度裁切。

## 间距和形状

| Token | 值 | 用途 |
| --- | --- | --- |
| `space_1` | 4vp | 紧邻标记 |
| `space_2` | 8vp | 控件内部、图文间距 |
| `space_3` | 12vp | 列表项内部 |
| `space_4` | 16vp | 普通页面边距/模块 |
| `space_6` | 24vp | 大模块分隔 |
| `space_8` | 32vp | 平板边距/强分区 |
| `radius_tag` | 4vp | 标签 |
| `radius_control` | 8vp | 小控件 |
| `radius_card` | 16vp | 独立内容卡 |
| `radius_action` | 20vp | 高频按钮 |
| `radius_modal` | 32vp | 顶层半模态 |

## 图标与地图资产

- 优先使用 HarmonyOS Symbol；自定义图标保持统一线宽、圆头和视觉重量。
- 定位、播放、分享、返回等图标不能一套填充一套描边混用。
- 地图点位至少具备默认、选中、聚合、当前位置和已点亮五种语义。
- 本地地图兜底资源必须保持比例，不拉伸中国轮廓。
- 应用图标发布前需完成前景/背景双层资源；当前 SVG 仅为工程占位。

## 动效 Token

| Token | 基线 | 用途 |
| --- | --- | --- |
| `motion_instant` | 100ms | 颜色、图标反馈 |
| `motion_short` | 150ms | 按压、选中 |
| `motion_panel` | 250ms 以内 | 面板非跟手落位 |
| `motion_page` | 350ms 以内 | 页面层级切换 |

跟手地图、面板拖拽不使用固定延迟；仅对结束后的落位使用曲线。
