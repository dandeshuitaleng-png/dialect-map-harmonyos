# 界面工艺规则

## 视觉命题

[设计推断] “地图承载乡土记忆，朱砂色只标记人与声音”。地图和真实内容负责识别，不依赖大标题、渐变或玻璃效果制造气氛。

## 信息层级

1. 地图与当前区域。
2. 当前可执行任务：定位、录音鉴定、打开护照。
3. 同乡人物与数量。
4. 解释性信息、模拟声明和辅助状态。

同一屏最多一个主强调动作。多个入口并列时，录音鉴定为主操作，乡音护照为次操作。

## 排版

- [官方规范] 使用 HarmonyOS Sans 或系统字体；尺寸用 `fp`，支持系统字体缩放。
- 中文标题避免人为增加宽字距；数字指标使用稳定数字宽度时需验证字体支持。
- 正文默认不低于 12fp 的设计基线；关键操作不靠 10fp 以下文字表达。
- 标题、正文、说明最多使用必要的五层语义，不用字号、颜色、字重同时制造同一层级。
- 长地区名、昵称和方言名称允许换行或按语义截断，不能撑破卡片。

## 色彩与材质

- 品牌强调只承担录音、选中点位和关键成功状态，不满屏使用。
- 状态色必须有图标或文字辅助，不仅依赖颜色。
- 普通列表不逐行卡片化；独立身份、结果或可分享内容才使用卡片。
- 毛玻璃只在确有地图浮层层级时使用，并验证可读性与性能。
- 不使用紫蓝渐变、统一大圆角白卡和无语义阴影作为默认设计。

## 间距与圆角

- [官方规范] 使用 4/8vp 间距体系，页面按 4/8/12/16/24/32vp 组合。
- 嵌套圆角满足“内层圆角小于外层圆角”，避免所有容器同为 20–32vp。
- 面板、弹层与安全区之间保留可操作空间，底部操作避让系统导航区域。

## 状态反馈

按用户可感知等待时间选择反馈：

| 等待时间 | 反馈 |
| --- | --- |
| 小于 300ms | 不额外展示，避免闪烁 |
| 300ms–2s | 保持布局的骨架或局部状态 |
| 2s–10s | 进度反馈与当前阶段说明 |
| 超过 10s | 超时说明、取消和重试 |

定位、录音、鉴定、播放、分享均需要按压反馈、进行中状态和结果反馈。

## 动效

- 动效只解释层级、连续性、跟手或状态结果。
- 简单状态约 100–150ms；面板切换不超过约 250ms；全屏层级切换不超过约 350ms。
- 地图和面板手势必须可打断并跟手，不使用装饰性 bounce。
- 减少动态效果下取消非必要位移、缩放、视差和回弹。

## 多输入与无障碍

- [官方规范] 手机、折叠屏和平板热区必须不小于 40×40vp，推荐 48×48vp。
- 点击、键盘 Enter/Space、鼠标左键表达同一意图。
- 地图缩放同时提供双指、按钮和键鼠路径。
- 面板不能只有拖拽手势，必须有可聚焦的展开/收起替代动作。
- 纯图标按钮提供动作型无障碍名称，如“定位到我的位置”。
- 弹层关闭后焦点回到触发按钮；阅读顺序与视觉顺序一致。

## 反模式

- 地图上增加不承担导航或状态责任的品牌标题。
- 把录音主按钮长期悬浮在地图中央，遮挡点位。
- 点击录音后无过渡地跳到完全无关的页面结构。
- 定位只改变文案，不移动镜头或显示位置。
- 面板看起来可拖动，但只能点击或只能停在一个高度。
- 护照只展示头像和两项百分比，遗漏地区、语音与社交信息。
