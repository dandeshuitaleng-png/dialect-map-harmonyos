# 产品与交互规格

## L1 定位与意图

[项目事实] 乡音地图是 HarmonyOS 完整应用，核心闭环为：

`全国乡音地图 → 录音鉴定 → 点亮地区 → 生成乡音护照 → 查看同乡`

首屏不是品牌展示页。地图是视觉主角，核心任务是探索同乡并进入鉴定或护照。

### 成功结果

- 用户能拖动、缩放地图并主动获取当前位置。
- 用户能展开同乡面板，查看附近、推荐和当前区域用户。
- 用户能在不丢失地图上下文的情况下完成录音鉴定演示。
- 用户能点亮地区并获得信息完整的乡音护照。
- 用户能从同乡列表进入他人护照。

## L2 信息架构

```text
全国乡音地图（一级）
├── 地图探索状态
├── 同乡面板（首页内）
│   ├── 附近同乡
│   ├── 推荐同乡
│   ├── 当前区域用户
│   └── 他人乡音护照（次级）
├── 录音鉴定任务（保留首页上下文的半模态或大窗口侧栏）
└── 我的乡音护照（次级）
    └── 分享乡音名片预览
```

[设计推断] 首页不增加独立品牌大标题；应用名称可留在系统任务信息、应用图标和必要的无障碍名称中。

## L3 核心链路

1. 首页加载地图或本地兜底图。
2. 用户浏览地图、选择地区或点击“我的位置”。
3. 用户从同乡面板进入录音鉴定。
4. 录音任务显示准备、录音中、已录制、鉴定中、结果五个阶段。
5. 用户确认结果，点亮地区并生成护照。
6. 护照展示身份、鉴定、语音、地区和社交信息。
7. 返回首页时恢复地图视口、面板高度和选中地区。

## L4 关键组件与状态

### 地图

- 加载中、正常、交互中、定位中、定位成功、无权限、定位失败、地图失败并降级。
- 定位成功必须移动镜头到当前位置并显示当前位置标记。
- 3D 地球只在受支持 API 与真实 Map Kit 状态下启用；失败时回退普通地图。

### 同乡面板

- 竖屏平板：紧凑态约 340vp、半展开态约 42%、充分展开态约 72%。
- 手机：紧凑态按内容高度约 340vp，展开态约 72%。
- 支持拖动把手、内容区域上滑和显式展开/收起动作。
- 拖动过程必须连续跟手；松手后按距离和速度吸附到最近层级。
- 面板高度改变不得重置地图、筛选或列表选择。
- 横屏大窗口使用侧栏，不把底部面板机械拉高。

### 录音鉴定

- 从首页进入时保留地图上下文，不使用无理由的全屏页面替换。
- 当前录音与鉴定属于演示，界面必须持续显示“模拟”或等价可信说明。
- 鉴定中禁止重复提交，失败后保留已录制状态并允许重试。

### 乡音护照

必须包含：

- 头像、昵称、所在地。
- 方言归属、鉴定置信度、乡音保留度。
- 代表语音及播放状态。
- 已点亮地区。
- 同乡好友、关注、被关注。
- 分享个人乡音名片入口。

## L5 边界条件

- 无网络：显示本地地图和缓存/模拟内容，在线能力标明不可用。
- 无位置权限：继续允许全国地图浏览，并提供再次授权路径。
- 地图加载失败：自动进入本地兜底，不出现空白主视觉。
- 当前区域无同乡：解释原因，并提供“查看推荐同乡”或“录下第一段乡音”。
- 窗口变化：保留当前页面、地图视口、面板状态、选中项与任务阶段。
- 大字体：正文和操作不得用固定高度裁切。
- 减少动态效果：保留状态变化，取消非必要位移、缩放和回弹。

## L6 验收标准

- 首屏 3 秒内能识别地图、同乡面板以及录音/护照入口。
- 地图上没有遮挡探索任务的品牌装饰标题。
- 定位授权成功后镜头确实移动；拒绝后应用仍可使用。
- 竖屏同乡面板能在紧凑、半展开和充分展开之间平滑吸附。
- 录音任务关闭后回到原地图状态。
- 护照七类信息全部可见且无截断。
- 手机、平板竖屏、平板横屏和自由窗口无关键内容遮挡。
- “构建通过”“已安装”“已运行”“真实服务可用”分别报告，不混为一谈。
