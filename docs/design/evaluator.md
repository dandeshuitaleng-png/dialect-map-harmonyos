# 乡音地图评估器

## 评估模型

乡音地图按任务型产品评审，不按营销落地页评审。

| 维度 | 权重 | 核心问题 |
| --- | ---: | --- |
| 产品意图 | 22% | 首屏是否服务地图探索、鉴定和护照 |
| 信息架构 | 22% | 地图、面板、任务和护照入口是否清楚 |
| 交互就绪 | 20% | 定位、拖拽、录音、返回和恢复是否可完成 |
| 领域可信 | 16% | 模拟、指标、位置和分享边界是否透明 |
| 系统工艺 | 12% | 字体、间距、Token、状态和多端是否一致 |
| 视觉品牌 | 8% | 视觉是否具有乡音识别且不压过任务 |

每个检查项使用：

- `2 / pass`：满足，可进行轻微优化。
- `1 / partial`：部分满足，已经影响体验。
- `0 / fail`：不满足。
- `critical_fail`：阻断交付，不能被平均分掩盖。

## 阻断项

- 首页找不到录音鉴定或我的乡音护照入口。
- 定位授权成功但镜头不移动，或拒绝后应用不可用。
- 同乡面板无法展开/收起，或拖动造成应用崩溃。
- 录音鉴定离开后丢失地图状态，且无恢复路径。
- 护照缺少需求指定的七类核心信息。
- 模拟鉴定被描述为真实 AI 结果。
- 原始录音或精确位置未经说明进入分享内容。
- 关键文字被裁切、按钮不可点击或系统返回失效。

## 证据链

1. **静态证据**：ArkTS、资源、权限声明、无障碍名称。
2. **构建证据**：Hvigor 主 HAP 与测试 HAP结果。
3. **安装证据**：签名、设备安装和包信息。
4. **运行证据**：应用启动、控制台错误和运行状态。
5. **操作证据**：关键点击、手势、权限和异常恢复。
6. **视觉证据**：各窗口截图与必要录屏。

视觉截图与静态结构冲突时，以用户实际看到的画面为准。构建成功不能替代安装和运行证据。

## 真机检查清单

### 首页地图

- [ ] 地图是首屏主视觉，没有不必要品牌标题遮挡。
- [ ] 点位与地图缩放、旋转、倾斜保持同步。
- [ ] API 15+ 设备上的 3D 地球能真实显示；失败有回退。
- [ ] “我的位置”只在用户操作后请求权限。
- [ ] 授权成功后镜头移动并显示当前位置。
- [ ] 拒绝或失败后给出说明，仍能浏览地图。

### 同乡面板

- [ ] 竖屏平板可在约 340vp、42%和72%三个层级连续拖动并吸附。
- [ ] 点击把手/替代按钮也能展开收起。
- [ ] 内容列表滚动和面板拖动没有明显抢手势。
- [ ] 横屏切换为至少 360vp 侧栏。
- [ ] 附近、推荐、当前区域用户均有正常和空状态。

### 录音鉴定

- [ ] 从地图进入，不丢失地图上下文。
- [ ] 准备、录音中、已录制、鉴定中、结果状态完整。
- [ ] 当前模拟能力说明持续可见。
- [ ] 处理中防重复触发，失败能重试。
- [ ] 关闭后回到原地图视口和面板状态。

### 乡音护照

- [ ] 头像、昵称、所在地。
- [ ] 方言归属、鉴定置信度、乡音保留度及解释。
- [ ] 代表语音和明确播放状态。
- [ ] 已点亮地区。
- [ ] 同乡好友、关注、被关注。
- [ ] 分享个人乡音名片入口。
- [ ] 分享预览说明不包含精确位置或原始录音。

### 多端与无障碍

- [ ] 手机、平板竖屏、平板横屏、自由窗口无截断。
- [ ] 大字体下文字换行，操作不消失。
- [ ] Light/Dark 层级和地图可读性成立。
- [ ] 所有关键热区不小于 40×40vp。
- [ ] 键盘能遍历定位、面板、列表、录音和分享。
- [ ] 减少动态效果下仍能理解全部状态。

## 回流索引

| 失败表现 | 回到文档 |
| --- | --- |
| 主任务不清、出现多余标题 | `spec.md`、`craft.md` |
| 指标含义混乱或模拟说明不足 | `domain.md` |
| 色彩、间距、圆角不一致 | `design-system.md` |
| 组件外观像但行为错误 | `components.md` |
| 平板、横竖屏或折叠错位 | `responsive-template.md` |
| 能力未实现或不能证明 | `gaps.log` |

## 停止规则

只有在以下条件同时满足时，才把版本标为可交付 Demo：

- 无 `critical_fail`。
- 六个维度均不低于 6/10。
- 产品意图、信息架构、交互就绪均不低于 8/10。
- 主 HAP 构建通过。
- 至少一个目标设备完成安装、启动和核心流程验证。
- 所有未完成真实能力在界面或 `gaps.log` 中明确标识。
