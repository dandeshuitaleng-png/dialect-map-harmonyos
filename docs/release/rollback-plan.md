# 1.0.0 发布与回滚方案

## 发布策略

1. 使用 AppGallery Connect 已登记的 `com.dialectmap.app` 和正式 release 证书生成签名 APP Pack。
2. 先提交内部或小范围测试版本，完成手机和平板核心链路、权限拒绝、Dark、大字体和系统返回验收。
3. 审核通过后分阶段放量；监控崩溃、启动失败、Map Kit 权限错误、录音占用和分享失败。
4. 扩大放量前确认隐私政策 URL、应用内说明和商店数据安全声明一致。

## 停止条件

- 启动或核心流程出现阻断性崩溃。
- 麦克风、位置或分享行为与隐私声明不一致。
- 正式签名、包名或 Map Kit capability 配置错误。
- 预置内容被误解为真实用户、真实 AI 或在线社交服务。
- 内容来源、版权或合规材料被审核方提出有效异议。

## 回滚动作

首发版本没有可回退的线上旧版本。出现停止条件时，发布负责人应立即停止放量或撤回待审版本；如已公开，则在 AppGallery Connect 使用平台允许的下架/暂停分发能力，并准备修复版本。

修复版使用更高的 `versionCode`（例如 `1000001`），不得复用已发布版本号。保留现有 Preferences 键名，确保用户的地区、方言分支和首次引导状态可以兼容恢复；若数据合同必须变化，应先增加向前迁移，不直接删除用户数据。

## 回滚核验

- 商店分发状态已停止或修复版已替换。
- 旧正式证书和已暴露凭据已按安全决定轮换或撤销。
- 修复版重新完成签名、构建、安装、运行、操作和视觉分层验收。
- 隐私政策、上架文案、截图和实际行为再次一致。
