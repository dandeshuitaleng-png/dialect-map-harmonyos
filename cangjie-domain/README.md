# 乡音地图仓颉领域层

该目录是与 ArkTS/ArkUI 界面分离的仓颉领域模型草案，覆盖方言鉴定、录音状态、百分比分数校验、地区点亮和乡音护照生成。

## 目录

- `src/dialect/`：鉴定结果、录音状态和分数边界校验。
- `src/passport/`：从鉴定结果生成乡音护照。
- `*_test.cj`：0、100、越界分数和地区点亮测试。

## 当前边界

本机当前未安装 `cjc` 或 `cjpm`，因此这些仓颉文件尚未经过编译器、格式化器或单元测试运行验证。HarmonyOS App 当前仍由 ArkTS/ArkUI 构建；该目录不会被 Hvigor 自动编译，也不代表仓颉代码已经接入 HAP。

安装与 `cjc-version = "1.0.5"` 匹配的仓颉工具链后，可在本目录执行：

```bash
cjpm build
cjpm test
```

后续正式接入应先固定 ArkTS 与仓颉之间的数据契约，再选择 C 互操作或目标平台支持的正式桥接方式；接入方式需要结合实际 SDK 和设备环境验证。
